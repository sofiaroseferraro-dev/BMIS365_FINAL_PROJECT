# Big Sky Boards Ingredient and Board Manager

## Business Problem
Big Sky Boards is a small catering business that makes fresh, low-priced
charcuterie boards for events. The owner does not track expiration dates on
her meats, cheeses, and fruit, so she throws out spoiled product and often
restocks too late, which delays customer orders. This app tracks ingredients,
their expiration dates, and pre-orders in one place.

## Business Question
At what stock level should we reorder each ingredient so we rarely throw out
expired product or delay an order?

## How to Run
1. Open the project folder in VS Code
2. Run `main.py`
3. Choose an option from the menu

## Menu Options
1. View ingredients
2. Add or restock an ingredient
3. View suppliers (coming soon)
4. View board menu (coming soon)
5. Record a pre-order
6. Show expiring and low-stock alerts (coming soon)
7. Remove expired items (coming soon)
8. Report with charts (coming soon)
9. Run 30-day simulation (coming soon)
10. Save and exit

## Files
- `main.py` - runs the menu
- `inventory.py` - loads, saves, shows, and updates ingredients
- `boards.py` - board recipes and pre-orders
- `ingredients.csv` - ingredient cost, quantity, expiration date, and reorder level
- `orders.csv` - pre-orders that have been recorded
